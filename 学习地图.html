1Python 语法基础第 1–5 节

语言本身
  • print() / 变量 / 字符串引号
  • 三种类型：int float str，互相转换
  • 列表：索引从 0 开始、切片含头不含尾、append
  • 字典：{"键": 值}，按名字取而不是按位置
  • 判断：if / elif / else，== 比较、= 赋值
  • 循环：for x in 列表、range() 按序号、enumerate
  • 函数：def、参数、默认值、return 不等于 print

2Qt 界面第 6、9 节

窗口是怎么长出来的
  • 五步骨架：app → win → 控件 → show → exec
  • 布局：QVBoxLayout 竖 / QHBoxLayout 横 / 布局可嵌套
  • addWidget 放控件、addLayout 放布局、setLayout 挂到窗口
  • 控件：QLabel QPushButton QComboBox QTableWidget
  • 表格要点：先 setRowCount/ColumnCount，再 setItem(行,列,格子对象)
  • 图表：pg.PlotWidget + curve.setData(x, y)
  • QSplitter：可拖动的上下分栏

3事件与信号第 7、11 节

程序为什么会对点击有反应
  • 事件循环：程序停在 app.exec() 等鼠标和键盘
  • 信号 → 槽：button.clicked.connect(函数)
  • connect 里绝不加括号：加括号会立刻执行一次
  • clicked 带 bool、currentIndexChanged 带 int
  • 槽函数要接住参数：def draw_chart(index=None)
  • blockSignals：批量改控件前先静音
  • QFileDialog.getOpenFileName 返回 (路径, 筛选器)

4数据处理第 8、11 节

pandas 的日常动作
  • pd.read_csv() → DataFrame（整张表）
  • df["列"] → Series（一列）；多一层方括号就还是表格
  • shape / columns / head() / iloc[行,列]
  • mean max min sum / to_list()
  • is_numeric_dtype：挑出能做纵轴的列
  • to_numeric(..., errors="coerce")：脏数据变 NaN 而不是崩
  • 数据源 ≠ 界面：计算都在 df 上，表格只是「画出来」

5代码结构第 12、13 节

怎么让代码不乱
  • 分层依据：它认不认识界面控件
  • data_utils.py：纯数据函数，不许出现 Qt
  • 依赖单向：界面 → 数据，不能反过来
  • 模块：import data_utils → data_utils.函数()
  • 类：class MainWindow(QWidget)、__init__、super().__init__()
  • self.df 取代 global df，每个窗口各有一份数据
  • if __name__ == "__main__": 防止被 import 时乱执行
  • 拆的是「组件」不是「步骤」；200 行不要拆

6交付打包第 14 节

从代码到别人能用的东西
  • pyinstaller --noconfirm --windowed --name X 文件.py
  • 产物：dist\X\X.exe + _internal\（180MB）
  • 不能只发 exe：要整个文件夹压缩
  • 打包后 __file__ 指向 _internal（资源文件的坑）
  • 闪退看不到错 → 去掉 --windowed 打 debug 版
  • --onedir 启动快 / --onefile 单文件但慢
  • 改代码必须重新打包；做成 打包.bat 一键搞定

⚠ 亲手撞过的坑（这些不是知识，是经验）

  • Qtwidgets / Qwidget 大小写 —— Python 区分大小写
  • PyCharm 自动导入猜错：from main import label 会直接启动第二个程序
  • 「未解析的引用 win」→ 不是错误，是名字定义在后面；别去 pip install win
  • column_columns 拼错 —— 报 AttributeError 先去查 def 清单
  • y.to_list() —— 上游改成返回 list 了，下游还在按 Series 用
  • KeyError: '收盘' —— 写死列名的代价，改成用户选列
  • 相对路径找不到文件 —— 用 os.path.dirname(__file__) 算绝对路径
  • 包发过去打不开 —— 忘了把 _internal 一起发
